**VISUAL PRODUCT SEARCH ENGINE**
- This is a Visual Product Search Engine that lets users upload any clothing image and instantly surface the 10 most visually similar products from a database — without typing a - single keyword.
- Internally Qdrant uses HNSW (Hierarchical Navigable Small World) graphs — a data structure that locates the nearest vectors in milliseconds across millions of entries, without scanning every single one.

- Software/Libraries/Tools Used: [Python, Qdrant, CLIP-Model,FastAPI,uvicorn ,Docker, Streamlit]` ·
 [🔗 Repo](https://github.com/FixerSoup/Visual_Product_Search_Engine)

**CUSTOMER SEGMENTATION CHURN PREDICTION WITH RECOMMENDATION AND RETENTION ANALYSIS**
- Many Beginner Data Scientists/Analysts face problems while working with segmenting customer,churn predictions, recommendation or retention analysis
- Here a static but **effective customer segmentation churn prediction model with recommendation and retention analysis** trained on Hugging Face [churn dataset](https://huggingface.co/datasets/d0r1h/customer_churn)
- Trained Random Forest Classifier for churn prediction and K-Means Clustering for Segmenting customers into k clusters based on top k features.
- Software/Libraries/Tools Used: [Python,Pandas,Matplotlib,Gemini Model(gemini-3.5-flash-lite),KMeans Clustering,Random Forest Classifier,]
[🔗 Repo](https://github.com/FixerSoup/Customer-Segmentation-Churn-Prediction-Retention-Recommendation-Analysis)

**CHURN ELABORATING CHART ANALYSIS REPORT**
- Here's a easy to use churn report generator which generates report on customer churn dataset.
- It cleans the raw dataset generates multiple visualizations including pie chart,bar charts etc which gets as an input to the Gemini AI model(gemini-3.5-flash-lite) and it generates a simple easy to understand chart analysis report for churn based on effect of churn per feature and explains the key insights from the visualizations based on those visuals.
- Software/Libraries/tools Used : [Python,Gemini Model(gemini-3.5-flash-lite),Pandas,Matplotlib, Seaborn ,MarkdownPdf]
